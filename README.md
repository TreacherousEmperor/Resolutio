# Resolutio
A League of Legends stats and match-tracking web application, inspired by op.gg and u.gg.

Resolutio lets players look up their League of Legends profile to view match history, champion statistics, rank progress, and in-depth game data - similar to tools like op.gg or u.gg, but built as an original project. Users can search summoner names to pull up recent games, KDA trends, win rates by champion, and other performance metrics pulled from Riot's official API.

The project currently runs on a personal Riot Developer API key, which limits it to smaller-scale, lower-traffic use rather than production-level deployment. Upgrading to a production key (and the scale that comes with it) is a possible future step.

Currently developed as a web application for a school project. Planned future expansion includes a desktop client and an in-game overlay.
